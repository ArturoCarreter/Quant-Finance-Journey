# High-Performance Black-Scholes-Merton Pricing Engine

A high-performance analytical engine for European option pricing and risk sensitivity (Greeks) calculation, optimized with **Numba JIT** and **NumPy**.

## 🚀 Key Features
- **Ultra-low latency:** Optimized with Numba for sub-millisecond execution.
- **Full Greeks Suite:** Analytical calculation of Delta, Gamma, Vega, Theta, and Rho.
- **Risk Visualization:** Dynamic plotting of sensitivity profiles (Delta/Gamma) vs. Spot Price.
- **Architecture Insight:** Comparative analysis between pure Python and JIT-compiled performance.
